AWS CloudFormation Lab

OVERVIEW
This lab demonstrates how to use AWS CloudFormation to create and manage infrastructure as code.

CloudFormation allows you to define resources (like EC2, S3) using templates and deploy them automatically.

OBJECTIVES
- Understand CloudFormation templates
- Create a CloudFormation stack
- Deploy AWS resources using templates
- Validate and test deployment

TOOLS USED
- AWS CloudFormation
- AWS Management Console
- S3 (for templates)
